replaced with permitted real data during implementation.
Core idea: create ONE merged market-intelligence dashboard. Do not create a separate dashboard for every competitor.
Every aggregate result keeps a link to the business and source review/post that produced it.

2. PROJECT OBJECTIVES
1. Identify a target business and comparable competitors.
2. Combine business, review, post and geographic information.
3. Analyze sentiment and recurring topics.
4. Measure content/post activity.
5. Produce market-level insights instead of separate competitor dashboards.
6. Preserve source attribution so every result can be traced to a company and record.
7. Allow filtering, hovering and drill-through in the final dashboard.
3. DATA PIPELINE
 PERMITTED DATA SOURCES → DATA COLLECTION → CLEANING → DATABASE → NLP/TOPIC ANALYSIS → BUSINESS-LEVEL
METRICS → MARKET AGGREGATION → INTERACTIVE DASHBOARD → SOURCE EXPLORER
Important: API availability and authorization determine which Google Business Profile/Places fields can actually be collected.
The design should not depend on scraping Google Maps pages.

20. WHAT MAKES THIS A STRONG PROJECT
The novelty is the merged intelligence + provenance approach. You are not merely comparing ratings. You are combining
multiple businesses into market-level insights while preserving the exact business and record behind each metric. This
supports interactive exploration, explainable analytics, NLP, database design, geographic visualization and business
intelligence in one project.
